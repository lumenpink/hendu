# hendu

Bot de WhatsApp em Rust para acessibilidade comunitaria: transcricao de audios e descricao de imagens e figurinhas

## 📋 Conformidade GOST

Este projeto adota a norma **[GOST](https://codeberg.org/lumenpink/gost)** (Gosplan Standard for Technical Software).
- **Versão GOST:** `1.1.0`
- **Linguagens declaradas:** `rust`
- **Licença:** `Apache-2.0`

## 🚀 Como Iniciar

```bash
# Clonar o repositório
git clone <url-do-repositorio>
cd hendu

# Verificar conformidade
cccp check
```
